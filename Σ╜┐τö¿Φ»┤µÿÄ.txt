========================================================
  挥砍水果 · Kinect 体感互动游戏
  Windows 部署与使用说明
========================================================

【本版改动】
  · 不再需要 Python，不再需要网页服务器
  · 直接本地打开 index.html，Chrome / Edge 自动进入全屏 kiosk 模式
  · 设定改完自动存在本机，断电重启不丢，不必每次导入 config.json
  · 所有脚本内的提示改成英文（中文在英文版 Windows 控制台会乱码）


【一】先确认这三样东西

  1. Windows 8 或以上
  2. Kinect v2 传感器（Xbox One 那款）+ 它的电源适配器
     ★ 电源适配器必须插上。只插 USB 不供电，设备不工作。
       这是现场最常见的故障原因。
  3. Kinect for Windows SDK 2.0
     下载：https://www.microsoft.com/download/details.aspx?id=44561
     装完重启一次电脑。

  浏览器：Chrome 最好，没有的话会自动用 Edge，两者都能全屏。


【二】第一次使用：编译桥接程序（只做一次）

  浏览器不能直接读 Kinect，需要一个本地程序把骨骼和画面转给网页。

  1. 打开 KinectBridge 文件夹
  2. 双击 build.bat
  3. 看到「SUCCESS - KinectBridge.exe is ready」就成功了

  不需要安装 Visual Studio，脚本用的是 Windows 自带的编译器。
  build.bat 会先自动关掉正在运行的 KinectBridge.exe 再编译，
  不用手动去任务管理器结束进程。


【三】日常开机：双击「启动游戏.bat」

  （同目录下的 START-GAME.bat 是同一个文件，两个名字随便点哪个）

  它做两件事：
    1. 启动 Kinect 桥接程序（最小化）
    2. 用 Chrome 或 Edge 全屏打开游戏

  游戏页面会自动连接桥接程序，断线每 3 秒自动重连。
  右下角出现玩家画面 = 一切正常。

  退出游戏：Alt + F4

  想开机自动启动：
    Win + R  →  输入 shell:startup  →  回车
    把「启动游戏.bat」的快捷方式拖进去


【四】操作方式

  玩家：
    举手过头 0.6 秒     开始游戏
    挥动手臂划过水果     切开水果加分
    别碰炸弹            碰到扣分

  流程是单向的：
    首页 → 点击或举手 → 游戏 → 成功页 / 失败页 → 倒数后自动回首页
    结算页不能直接重开，必须回首页才能开下一局。
    结算页停留秒数可调（设定 04），倒数不显示在画面上。

  工作人员：
    Q 键 或 双击屏幕右上角   进入 / 退出设定后台
    Esc                     退出设定
    Alt + F4                关闭游戏

  没接 Kinect 时可以用鼠标测试：移动鼠标就是挥刀，不用按键。


【五】设定后台（8 个分页）

  01 屏幕与页面   分辨率（默认 1080x1920 竖屏）、四张页面图、文字
  02 水果         数量、图片、分数、权重、汁液颜色
  03 炸弹         数量、图片、扣分、出现比例
  04 玩法与胜负   时长、目标分、结算停留秒数、抛出节奏、连击、画面可读性
  05 音乐与音效   背景音乐、切中、炸弹、成功、失败等 7 条
  06 设备与输入   鼠标测试、手柄、双手刀锋
  07 体感摄像头   小窗位置大小、镜像、骨骼线、手部活动范围
  08 配置存档     导出 / 导入 config.json

  ★ 关于设定保存
    改完设定点「保存并退出」即可，直接存在本机浏览器里，
    关机重开都还在，不需要做别的事。

    「08 配置存档 → 导出 config.json」的用途是：
      - 备份，防止误操作恢复出厂设置
      - 换机器、装第二台设备时快速复制同一套配置

    换机器时把 config.json 和 index.html 放同一目录，
    新机器第一次启动会自动读取，之后就存在本机了。


【六】现场调试顺序

  出问题时按这个顺序排查，能快速定位：

  1. 单独双击 KinectBridge\KinectBridge.exe
     看控制台有没有报错。正常会显示两个地址。

  2. 浏览器打开  http://127.0.0.1:8181/video
     能看到实时画面 = Kinect 正常。
     看不到 = 检查电源适配器、USB 3.0 接口、SDK 安装。

  3. 再启动游戏。
     设定 → 07 体感摄像头，看状态灯是不是绿的。


【七】性能调优

  机器带不动时，用记事本编辑「启动游戏.bat」里这一行：

    set BRIDGE_ARGS=--port 8181 --width 960 --fps 20 --quality 70 --cutout --bg 0B1F26

    --width 960     画面宽度，改成 640 省一半 CPU
    --fps 20        画面帧率，改成 15 也够用
                    （骨骼始终 30fps，改这个不影响操作手感）
    --quality 70    JPEG 质量，改成 55 省带宽
    --cutout        抠像：只显示人物、去掉背景
                    不想要就把这个参数删掉
    --bg 0B1F26     抠像后的背景色

  游戏端还能再省：
    设定 04 → 把「水果光晕强度」调到 0
    设定 04 → 把「刀锋拖尾长度」降到 100ms


【八】现场参数建议

  竖屏大屏、商场排队场景：
    游戏时长 60 秒，目标分 150，炸弹比例 18%
    水果大小 18%（玩家站得远，要调大）
    手部活动范围 60%（玩家不用把手伸到极限，省力）
    结算停留 8 秒

  展会短平快、人流量大：
    游戏时长 30 秒，目标分 60
    抛出间隔 900ms，难度递增开启
    结算停留 5 秒


【九】常见错误对照表

  浏览器显示 ERR_CONNECTION_REFUSED / 127.0.0.1 refused to connect
    → 旧版脚本要跑 Python 网页服务器，没装 Python 就会这样。
      本版已完全去掉服务器，不会再出现。

  游戏打开了但没有全屏，还带着地址栏和标签页
    → 旧版被 Edge 接管，没有传全屏参数。
      本版会依次找 Chrome、Edge，两者都用 kiosk 全屏模式启动。

  error CS0016: Could not write to output file ...
  'being used by another process'
    → KinectBridge.exe 正在运行，编译器覆盖不了它。
      本版 build.bat 会自动先关掉它。

  error CS0104: 'Encoder' is an ambiguous reference
  error CS1984: Cannot await in the body of a finally clause
    → 旧版源码问题，已修复。若仍出现说明用的是旧 Program.cs，
      请重新解压覆盖整个文件夹。

  控制台显示方块或乱码
    → 旧版脚本含中文。本版全部英文，不会再出现。

  找不到 Microsoft.Kinect.dll
    → SDK 没装或装在非默认路径。

  游戏页面右下角一直显示「未连接」
    → 桥接程序没启动，或端口 8181 被占用。
      先单独跑 KinectBridge.exe 看控制台报什么。

  index.html          游戏本体（单文件，含全部设定后台）
  启动游戏.bat        一键启动（全屏）
  START-GAME.bat      同上，英文名副本

    build.bat         一键编译
