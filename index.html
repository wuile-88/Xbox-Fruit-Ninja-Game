体感双手

建议先用 0.3 左右，骨骼点抖动明显时再往上加。

接 Kinect / Xbox 体感设备：用 WebSocket 把骨骼坐标转发进来即可，游戏逻辑不用改。
window.Bridge.hand(0, x, y) 右手，x/y 为 0~1 归一化坐标（0,0 是左上角）
window.Bridge.hand(1, x, y) 左手（需开启双手刀锋）
window.Bridge.release(0) 该只手离开画面，收起刀锋
window.Bridge.start() 触发开始 / 重玩，可绑定「举手」手势
window.Bridge.status(true) 点亮左下角设备状态灯
画面默认做左右镜像：玩家举右手，刀锋出现在屏幕右侧，符合照镜子的直觉。要关掉改 Bridge.mirror = false。

体感摄像头

Kinect v2 的骨骼与画面由本机桥接程序 KinectBridge.exe 提供，游戏自动连接、断线自动重试。

未连接桥接程序请先运行 KinectBridge.exe

连接

桥接程序和游戏在同一台机器时保持默认。若跑在另一台机器上，填对方 IP 和端口。

小窗位置与外观

显示内容

抠像（只显示人物、去掉背景）在桥接程序端开关，启动参数加 --cutout。

操控

活动范围是把摄像头画面中间这一块映射到整个屏幕。设 70% 表示玩家手只要在画面中间 70% 的区域移动，就能覆盖屏幕左右两端，不用把手伸到极限。双手刀锋在「设备与输入」里开。

Windows 现场部署步骤：
1. 装好 Kinect for Windows SDK 2.0，插上 Kinect v2 和它的电源适配器（这个适配器必须有，只插 USB 不供电）。
2. 运行 build.bat 编译出 KinectBridge.exe（不需要装 Visual Studio）。
3. 双击 启动游戏.bat，它会先起桥接程序，再用 Chrome 全屏无边框打开游戏。
4. 想开机自启：把 启动游戏.bat 的快捷方式放进 shell:startup 目录。
桥接程序同时提供 ws://127.0.0.1:8181/ws（骨骼数据）和 http://127.0.0.1:8181/video（MJPEG 画面），浏览器里直接打开后者可以单独确认摄像头是否正常。
